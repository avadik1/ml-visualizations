# ML Visualizations

Воспроизводимые учебные визуализации математики и ML/NLP на русском языке.
Основной интерфейс — Jupyter Notebook в VS Code или JupyterLab.

Первая визуализация: Rotary Position Embedding (RoPE), в разработке.
В Git хранятся исходники без notebook outputs; результаты выполнения остаются локально.
