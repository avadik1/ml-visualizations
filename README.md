# ML Visualizations

Постоянные учебные визуализации математики и ML/NLP на русском.

## RoPE

[notebooks/rope.ipynb](notebooks/rope.ipynb) — интерактивная демонстрация Rotary Position Embedding для одной головы внимания:

- исходные и повёрнутые координаты выбранной пары с равным масштабом осей;
- частоты и углы всех пар с выделением выбранной;
- сравнение прямого score, относительной формулы и общего сдвига;
- полный dot product по относительному сдвигу и отдельные вклады пар.

В ячейке **CONFIG** собраны `d`, `base`, `seed`, `m`, `n`, `c`, `pair`, `delta_range`.
После Run All появляются контролы и кнопка **Сброс к CONFIG**. Ползунки обновляют вычисления и графики после отпускания.
При смене `d` или `seed` векторы воспроизводимо создаются заново; позиции, `base` и выбранная пара сохраняют исходные `q/k`.
Неверные CONFIG и формы векторов дают явный `ValueError`; равные концы диапазона Δ дают сообщение в интерфейсе.

## Установка

Проверено на **macOS 15.5 arm64, CPython 3.13.2**. Требуется Python 3.13 и Git.
Прямые зависимости закреплены в `requirements.txt`; **все транзитивные версии** проверенного окружения — в `requirements.lock` (снимок pip freeze без локального editable-пути).
Lock рассчитан на проверенную платформу; другие ОС и версии Python не проверены.

Из корня `ml-visualizations`:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m pip install --no-deps --no-build-isolation -e .
python -m pip check
```

Стек: NumPy 2.5.4, Matplotlib 3.11.2, ipywidgets 8.1.9, ipykernel 7.4.0, JupyterLab 4.6.6.
Для проверок: pytest 9.2.0 и nbclient 0.11.0. Manim, обучение и загрузка весов не требуются.

## Запуск в VS Code

1. Откройте **папку `ml-visualizations`** в VS Code с расширениями Python и Jupyter.
2. Откройте `notebooks/rope.ipynb`.
3. В **Select Kernel → Python Environments** выберите `.venv/bin/python` этого проекта.
4. Нажмите **Run All**, затем меняйте контролы под CONFIG. При правке самой CONFIG снова выполните Run All.

Глобальная регистрация ядра и изменение настроек Git не нужны. Если виджеты не появились, проверьте выбранное окружение и доверие к локальному notebook.

Альтернатива с тем же окружением:

```bash
source .venv/bin/activate
python -m jupyterlab notebooks/rope.ipynb
```

GitHub отображает исходники; **для интерактивности нужен локальный живой Python kernel**.

## Обозначения и соглашения

Все индексы с нуля. Чётная размерность `d` разбита на соседние пары `(0,1), (2,3), …`.
Для `i = 0,…,d/2−1` частота `θᵢ = base^(−2i/d)`, угол в позиции `p` — `pθᵢ` радиан.
Положительное вращение вектора-столбца против часовой стрелки:

```text
R(α) = [[cos α, −sin α],
        [sin α,  cos α]]
```

`R_p` — блочная матрица вращений всех пар. Для фиксированных `q`, `k` после проекций:

```text
q_m = R_m q,  k_n = R_n k
q_mᵀ k_n = qᵀ R_(n−m) k
```

Пары NumPy хранятся строками: операция соответствует `pair @ R(α).T`.
Код использует эквивалентные покоординатные формулы в `float64`.
Дуги показывают остаток угла с сохранением знака; полные обороты опущены, полные углы даны в таблице.

Dot product не является вероятностью внимания. Scaled attention logit — `q_mᵀ k_n / sqrt(d)`;
вероятности возникают после softmax по ключам с учётом маски.
Синтетический score может колебаться и **не обязан монотонно убывать с расстоянием**.
Это стандартный RoPE с полным вращением; масштабирование контекста и поведение обученной модели не моделируются.

Первоисточник: [Su et al., *RoFormer: Enhanced Transformer with Rotary Position Embedding*](https://arxiv.org/abs/2104.09864).
API: [ipywidgets](https://ipywidgets.readthedocs.io/en/latest/reference/ipywidgets.html), [Matplotlib](https://matplotlib.org/stable/users/explain/figure/backends.html).

## Проверки и локальные результаты

```bash
source .venv/bin/activate
python -m pytest -q
python scripts/verify_notebook.py
```

Тесты проверяют нулевую позицию, нормы пар и вектора, относительную формулу, общий сдвиг,
независимый матричный эталон, неверные формы и знак `d=2, q=(1,0), k=(0,1), m=0, n=1 → −sin(1)`.
Допуск `rtol=1e-11, atol=1e-12` выбран с запасом для округления float64 при `d≤32, |p|≤1024`; это не обещание точности для произвольно больших позиций.
Отдельно проверяются события всех контролов, пересчёт PNG, сохранение `q/k`, индексы после смены `d`, сброс, ошибка диапазона и данные графиков.
Это автоматические проверки Python-обработчиков; работа frontend непосредственно в VS Code не проверена.

`verify_notebook.py` запускает все ячейки в новом ядре текущего Python без глобальной регистрации и сохраняет **отдельную** выполненную копию `exports/rope.executed.ipynb`.
Исходный notebook остаётся без outputs. Графики просмотрены локально для настроек по умолчанию и `d=32` с граничными позициями.
Все `exports/`, `media/`, `renders/`, кэши и корневой `session_log.md` исключены из Git. Перед публикацией проверяется также содержимое самого `.ipynb`: `.gitignore` не удаляет встроенные outputs.

Математика: `src/ml_visualizations/rope.py`; представления и контролы: `src/ml_visualizations/rope_demo.py`. Логика в notebook не дублируется.

**Один шаг для исследования:** оставьте `q/k`, `m`, `n` фиксированными, меняйте только `c` и сопоставьте движение стрелок с неизменностью полного score.
